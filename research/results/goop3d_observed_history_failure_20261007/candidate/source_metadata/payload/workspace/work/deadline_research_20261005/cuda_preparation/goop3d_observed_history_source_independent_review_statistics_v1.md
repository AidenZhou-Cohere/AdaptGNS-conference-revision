No p-values, frame independence claim, survivor aggregate or pooled-material statistic is introduced.

## Boundaries and practical limits

The observed file allowlist contains only exact original observed protocol, JSON row and NPZ artifact paths. It checks all pins/byte counts before use and rechecks every selected file afterward. It does parse the full pinned 659,091,312-byte accepted collection, which may contain autonomous scalar results. The proposed `autonomous_array_or_result_read=false` field therefore overstates the read restriction. The implementation agent agreed to replace it with precise whole-collection, queue-file and numerical-aggregation flags.

Collection bound is 1 GiB; JSON bound is 16 MiB; each compressed archive, ZIP decoded-size sum, and final array-byte sum are bounded at 8 GiB. NPZ uses `allow_pickle=False`, unique flat member names, no encryption or object arrays, and the worker has a 32-GiB address-space limit. The final array-size check occurs after NumPy load; this is not a proof against hypothetical pathological preallocation. The exact hash-bound original archives and address-space guard make this a documented implementation limit rather than a demonstrated defect.

The independent scalar checker uses relative tolerance 1e-10 and absolute tolerance 1e-12, inherited from the original auditor. It supports scalar consistency at that tolerance, not exact independent confirmation of the sign of arbitrarily tiny effects. It does not independently reread the model, source data or original queue arrays. Saved diagnostic timing arithmetic does not establish native clock truth or end-to-end speedup.
