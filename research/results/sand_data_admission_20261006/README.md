# DesignSafe Sand source admission

The repository-linked [DesignSafe Sand dataset](https://doi.org/10.17603/ds2-0phb-dg64) supplies NPZ files directly. This preparation uses those published arrays; it does not reconstruct TFRecords. All 1,000 training and 30 validation trajectories have 320 frames, float32 positions, and int64 type-6 particles. Six input frames leave 314 forecast steps and 314,000/9,420 eligible training/validation histories. No test file was acquired or decoded.

The numeric repackager preserves trajectory order, dtype, shape and element values, verifies full source SHA256, every ZIP member CRC, and numeric save/reload equality, and retains the original archives. Train particle counts range from 107 to 1,976; validation from 218 to 1,929. Source boundary excursions are recorded without clipping. Exact dtype/shape/value duplicates were absent within/across these two splits; this is not a semantic near-duplicate audit or an independence claim.

The files here include source and numeric-manifest hashes, per-trajectory structural evidence, reviewed repackager and synthetic checks, and the initial unsuccessful acquisition attempt. That attempt downloaded no payload because the official response used an additional DesignSafe download hostname; separately recorded v2 admitted that observed official host. Two unsuccessful synthetic decoder-test iterations and their resolutions also remain in the review record.

Numeric dataset arrays and the original NPZ archives stay outside Git. The manifests document them but are not runnable without those arrays. The original acquisition receipt can be supplied to the exact-source repackager after acquiring byte-identical NPZs; a new acquisition receipt changes provenance/manifest hashes and must be distinguished. See the command-line help and review notes for the fresh-output requirement. Root verified 5,150 per-record correspondences after 27 synthetic tests plus 36 parameterized subtests passed.

This is source compatibility evidence, not a scientific training result. CUDA numerical validation, real-data runtime and complete-cohort deadline admission remain separate gates. Historical Sand aggregates have already been inspected; the forthcoming study must remain exploratory. No frozen WaterDrop source, model or result was changed.
