# Goop global action-gate preparation

This package preserves the reviewed source for a prospective whole-state
expand/stay gate on the three fixed Goop 2D mix models. It contains the frozen
protocol, implementation, release templates, synthetic tests and review history.
**It contains no scientific outcomes and grants no data, model, capacity or
execution admission.**

The gate uses eleven current-history features and a ridge head to predict the
signed error benefit of requesting expansion. The fixed study requires 24,000
training labels, 450 validation labels, 36 training capacity outcomes and 360
full test outcomes across three seeds and four policies. Validation selects one
common ridge penalty; the threshold stays zero. The random gate matches the
frozen validation request rate, which is not a guarantee of equal test compute.
The protocol and complete-cost decision remain binding even if the work cannot
finish. No partial favorable demonstration replaces the fixed study.

## Limits and execution boundary

Execution needs separate releases bound to the actual complete cohort, original
assets, clocks, capacity and process ownership. The gate follows the original
Goop work on aquamarine GPUs 0/1 and must preserve the fixed October 7, 04:00 UTC
complete-work boundary and all reserves. An unbacked preflight credit or a
label-rate estimate alone cannot admit the whole study. Shared-host timing
remains labelled as such.

Datasets, checkpoints, live outputs, private process inventories, SSH
configuration and credentials are excluded. Detailed synthetic fixture payload
trees remain local; their compact reviews, generating tests/probes and selected
historical source snapshots are retained. Exact directory references appear in
`omitted_synthetic_fixture_tree_references.json`. Oversized raw review logs, if
present in the selection, are referenced by hash in
`large_local_log_references.json`; none was needed here.

Software preparation and synthetic checks do not establish model accuracy,
complete evaluation, isolated runtime, independent test confirmation or
submission readiness. This prospective gate remains distinct from the earlier
native-graph studies and their empirical outcomes.
