# Sand original native-closure observation

This package is inert source preparation for root. It issues no analysis phase,
release, evaluation closure, numeric summary, remote write or target signal. The
frozen Sand analysis package 914e6e2df11836079f721a675bdbfcd9673b6bada3074fe766c52d085a37640b
remains unchanged. Its original sessions remain A51595 and B12559.

The intended use is a bounded observation before any proposed cleanup of a stale
original local transport. Original tool exit and remote evaluator exit are
explicitly unknown in every report. An observed native closure is not an original
tool exit, an evaluation admission or numerical completion.

## Root-only call

Use the workspace Python with this directory's `root_observe.py`:

```text
--root-observe --role A --package-sha256 <reviewed manifest SHA256>
--output /absolute/canonical/fresh/observation/directory
--https-proxy http://127.0.0.1:<root-owned-current-metadata-proxy-port>
```

Repeat for B with a different fresh output directory only as a separately
recorded original observation. The already reviewed metadata-only proxy remains
limited to 60 seconds. Each invocation has a 35-second complete local envelope,
a remote GNU timeout with SIGKILL at 20 seconds, and a 12-second internal read
bound. Root must ensure the proxy has enough remaining time for the invocation;
use a separate fresh bounded metadata proxy when needed. No proxy lifetime is
extended by this package.

The optional proxy applies only to the new SSH child's environment. The existing
SSH configuration, authentication, host verification and opaque TLS remain
unchanged. This observer may clean up only its own newly created local transport
group. It cannot signal either original Sand transport or any scientific process.

## Exact observation scope

On the exact original host and boot, the helper reads only the pinned original
root release and these original queue metadata documents: release_snapshot.json,
queue_status.json, coverage_ledger.json, process_outcomes.json and
(optional in schema, effectively required for these started runs)
gpu_observations.json. Reads are size-bounded, reject symlinks and special files,
check file identity while reading, and are rehashed before the final native sample.

The full child-accounting validator is copied without AST changes from the
frozen Sand analysis helper. It checks all 16 A / 8 B stage rows, all streams,
every registered child and outcome, original startup identities, argv, parent,
start ticks, signals, quota flags and genuine integer recorded child exits.
Failure and never-started outcomes are preserved. An incomplete or inconsistent
registry cannot add arbitrary PIDs to the native observation scope.

Every historical PID, original owner PID and validated registered child PID is
sampled twice using only /proc/<pid>/stat. Present or reused PIDs fail strict PID
absence. No unrelated command lines are read. The final sample follows metadata
rehashing. Exact GPU UUID mapping and assigned-device emptiness are observed
twice using only the two fixed nvidia-smi query types, each individually bounded
to two seconds and inside the observer's GNU-timeout process group. B devices
0–1 are observed without control; devices 2–3 must be empty. All A devices must
be empty.

For the 16/8 exact released stage directories, the helper lists top-level
basenames, types and byte sizes twice. It does not recurse, hash or open any
scientific result, protocol, summary, status, checkpoint, array or model inside
those stage directories. Filename availability or an unchanged directory is not
numerical completeness. Missing or changing availability is recorded explicitly;
it does not convert an absent process into a successful evaluator.

Root must inspect the original new observation tool exit, transport receipt and
remote report. Only `native_closure_observed: true`, complete historical registry,
stable metadata, exact boot, both strict native-absence samples and both empty
assigned-device samples support the native prerequisite for original local
transport cleanup. The report keeps `original_tool_exit_observed: false`, null
original tool/evaluator exit codes, and no analysis admission even in this case.

## Honest subsequent transport transition

If the original tool sessions return naturally, preserve their original completed
responses and original A/B.evaluation.external.json and use the frozen operator's
normal record-evaluation-exit and close-evaluation actions.

If they remain stale after independently reviewed full native closure, root may
prepare a separate scoped local-transport interruption record. First bind the
actual original local SSH process identity and its descendants to the original
`.evaluation.command.json`, root wrapper ancestry, process group and start
identity. Only that verified original local transport group may be cleaned up.
Keep the original Python operator wrapper alive so its existing finally block can
reap the SSH child and write the original stdout/stderr/external receipt. Preserve
the pre-cleanup observation and every cleanup signal/result separately.

Then wait on the same original A51595/B12559 sessions to actual completion. Bind
each unmodified completed tool envelope to its original session and actual integer
exit code; still-running envelopes and missing exits cannot satisfy this gate.
The SSH return code and original tool return code may differ and must both remain
verbatim. A transport-interruption nonzero code must never be described as the
remote evaluator's exit or as numerical failure/success.

The existing frozen record-evaluation-exit, close-evaluation and begin gates
already accept a genuine nonzero original evaluation-tool exit together with the
reaped original local transport and fresh complete native closure. Do not
fabricate exit zero, manufacture an external receipt, rename a replacement tool as
the original session, alter the frozen closure status, or replace the owner. If
the original sessions still cannot return completed evidence, the frozen exit
condition remains unsatisfied; a different explicit bridge would require review.

After both genuine original exits and fresh frozen native closures, root can run
local `begin` once. All subsequent phase-bound proxy startup, staging, reviews
and scientific analysis consume that one unchanged full 3600-second interval,
ending by 2026-10-07 04:00 UTC. This observation package cannot start that phase.
