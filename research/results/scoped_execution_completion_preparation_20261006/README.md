## Reconstruct the source layout

The package is an overlay on [the previously published preparation workspace](../goop3d_vectorized_preparation_20261006/README.md). `dependency_paths.json` lists every predecessor workspace path and hash, bound to its manifest. Restore those listed files into a **new** workspace at their recorded relative paths, then overlay this package's `workspace/` files. This supplies the unchanged numerical core, evaluator, lifecycle, source readers and synthetic fixtures without silently using whatever happens to be installed in a developer's work directory. Do not overlay active research sources or outputs.

The v2 Goop scalar module and its fixture are also copied locally because the new scoped entry imports that module immediately. These unchanged copies supply scientific functions; their older whole-host collection entry is not the scoped runtime. Other predecessor helpers remain explicitly referenced rather than duplicated. Original review logs can contain absolute developer or synthetic temporary paths; these are provenance, not portable invocation arguments.

`source_inventory.json` lists every copied file, original relative path, size, SHA256 and role. `manifest.json` binds the complete final package. `FILELIST.txt` is its plain-text file list. `verify_bundle.py` checks package bytes and referenced predecessor bytes without executing any research. `packaging_checks.json` records the narrow import/default-mode and relocation tests performed on reconstructed packaged files.

Run `python3 verify_bundle.py` from this directory with the predecessor family alongside it. The optional `--original-workspace /path/to/workspace` flag also checks only the exact original source paths listed in the inventory. `curate_sources.py` preserves the selection rule used to copy the preparation source and reviews; it refuses to overwrite an existing family. It does not install packages or run scientific stages.
