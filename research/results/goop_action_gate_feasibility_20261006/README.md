## Scope and reuse

This is a focused supplement requiring the existing pinned repository numerical helpers and runtime. It is not a standalone simulator distribution, a new execution release, or authorization to run a test phase. Preserve the original protocol and source lineage when using these files. Existing published-study packages were not modified.

No native/live process inventories, owner/session logs, raw model/checkpoint files, source arrays, NPZ payloads, credentials, test inputs or test outcomes are included. Original member JSON bytes are preserved inside deterministic USTAR/gzip archives. Numeric artifacts remain outside this package; their recorded hashes do not imply a new local numeric audit.

The manuscript copies include only the reviewed appendix addition relative to the saved prior versions. Removing one newline plus the exact v2 fragment recovers all prior bytes. The native compiler receipt is pinned to the included compiled source. No scientific tests or experiments were rerun for packaging.
