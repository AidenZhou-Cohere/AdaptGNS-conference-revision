\paragraph{Exploratory whole-graph action gate.}
We fitted a history-conditioned gate to the signed one-step whole-graph
benefit $b=\mathrm{MSE}_{\mathrm{base}}-\mathrm{MSE}_{\mathrm{random25}}$,
using three frozen mixed-graph Goop models trained for 100,000 updates.
Positive predictions request randomized expansion of the base graph.
The 11 history features summarize particle count, displacement,
second differences, wall distances, outside-particle fraction,
and coordinate excursion; the target concerns complete graph actions.
All 24,000 training and 450 validation paired-action labels were complete.
Ridge candidates $\lambda\in\{0.001,0.1,10\}$ used training-only
normalization; validation selected the common $\lambda=0.1$.

The planned evaluation comprised four policies (base, random25, learned
gate, and a random gate using the validation expansion rate), three models, and
30 test sources: 360 H395 outcomes. Admission required all 36 train-only
capacity outcomes to complete on three particle-count-selected sources.
Instead, 32 completed, one encountered a graph resource guard, and three
were unexecuted. For seed 2, source 988, the base policy's candidate
universe, before capping or policy selection, reached 100,498 pairs against
a 100,000-pair limit at forecast
261, after 260 committed forecasts. The protocol therefore left test
evaluation unadmitted. No held-out comparison was executed. This base-policy resource guard
does not establish nonfinite instability or failure of the learned gate.
