# Goop 2D native CUDA preparation and frozen launch

This family preserves completed source conversion, auxiliary census, native CUDA
implementation checks, six 512-update capacity probes and the fixed declarations
for a separate faithful base/mix, seeds 0/1/2, 100,000-update study. Scientific
training was active at curation. This family contains no completed scientific
cohort or efficacy results; the saved `six_scientific_jobs_running` launch state
is historical, not a live status service.

The six capacity probes were verified as infrastructure measurements. Their
training-only planning term is 24,564.989 seconds under
`1.35 * (100000*q6 + 12*r6)`, with `q6=0.17619390705034935` and
`r6=48.074801256880164`. The original capacity report leaves terminal/evaluation
costs and full-study fit null. Later quota-v2 declarations are separate execution
allocations; they do not retroactively turn that incomplete forecast into a
successful complete-study timing gate. Capacity checkpoints are not scientific
initializations or completed endpoints.

The original saved-batch preparation failure, its review, corrected second
attempt, implementation validation, source/delta reviews, capacity per-job
configuration/history/logs and frozen root releases are preserved. The scalar
analysis code was reviewed before use: final aggregation requires verified
input integrity and recovers only exact valid-prefix aggregate snapshots after
interruption. Required missing values remain null, with no survivor means.
The main interaction is `(mix risk-random) - (base risk-random)`; its sign alone
does not establish absolute risk-policy superiority.

`raw_evidence.tar.gz` stores every selected evidence file byte-for-byte, including
large scalar reports and unsuccessful outputs. `archive_members.json` records
original preparation-relative paths, hashes and sizes. `records/` contains exact
copies of smaller reports/protocols for convenient review; historical drafts
retain their original wording and do not override final declarations.
`omitted_inventory.json` identifies local omitted checkpoints/transport files
and excluded mutable/private operational records. Trajectory/type/context arrays
and checkpoints are not distributed; their descriptor/report hashes remain.
No SSH, connection, authentication or credential files are included.

The exact runnable source, frozen numerical dependencies and CPU replay command
are in [the shared source family](../cuda_graph_support_sources_20261006/README.md).
The reserved-test preparation code is included there as a reviewed, gated
candidate; this snapshot contains no official test acquisition or final metrics.
