# Exploratory actual-action benefit evidence

This package contains the completed, audited post-inspection analysis of the actual saved graph actions from the six-model full WaterDrop study. It does not replace the locked evaluation or add independent test trajectories. It contains no model inference results beyond the already saved predictions.

- `results.json`: every objective/seed/trajectory scalar, paired comparison, oracle portfolio, null/coverage count, and per-frame record index.
- `report.md`: the analyzer's original report, preserved byte-for-byte.
- `findings.md`: audited interpretation, seed values and next experimental question.
- `input_identity.json`: original input/source SHA256 inventory and execution provenance.
- `status.json`: original committed completion and result/report hashes.
- `independent_audit.py` and `independent_audit.json`: separate mathematical/provenance implementation and its successful report.
- `omitted_raw_files_sha256.json`: SHA256 and original pointers for all 3,564 omitted per-frame JSON/NPZ analysis files.
- `manifest.json`: package file hashes and unchanged copied-source identities.

The 1,782 raw source same-state archives and 1,782 derived analysis archives are not included. Hashes are identity records, not downloadable data or a substitute for absent files. The package preserves all scalar outcomes and derived-file pointers; recomputing per-particle diagnostics requires the original source archives. Previous-observed-base risk is teacher-forced and differs from autonomous cached-own-graph risk. Hindsight portfolio results use targets and cannot be deployed.

## Reproduction

From the repository root, with the recorded NumPy/SciPy environment and the complete source evaluation directory available:

```sh
python -m research.analyze_full_action_benefit --evaluation-root /path/to/workspace/work/full-evaluation/same_state --output-dir /path/to/workspace/work/full-action-benefit-20261005
```

The analyzer requires a new output directory and verifies all original inputs. It loads no checkpoints, performs no inference, and refuses incompatible or invalid sources. Missing/failed required measurements remain null. This command writes a new execution record with new paths/timestamps; the publication retains the original execution bytes.

The preserved independent audit script uses the workspace layout of this study. For reproduction, place it at `/path/to/workspace/work/full-action-benefit-audit-20261005/audit.py`, keep the repository at `/path/to/workspace/outputs/AdaptGNS`, and keep the new analysis at `/path/to/workspace/work/full-action-benefit-20261005`. Run it with the same Python environment. It reads the input root from the new analysis identity file and writes a timestamped attempt report alongside the script. It does not alter source evaluation or analysis files. Reusing the publication's original identity file requires access to its recorded original paths; portable regeneration requires running the analyzer first with the available input location.

The original successful audit verifies all 1,782 frames, 3,582 source files and 3,568 analysis files with 79,192,129 element/structure checks. These counts are software verification, not independent statistical samples. There were no failed audit attempts in this audit family.

This is nonanonymous research-fork evidence. Submission anonymization, asset rights and author verification remain separate requirements. `rendered/` contains the seed-level mechanism figure and standalone LaTeX inserts generated by `research/render_full_action_findings.py`. Its manifest pins both input summaries. The earlier version of the figure and a syntax-only rendering failure are preserved in the local working record; no scientific output was changed.
