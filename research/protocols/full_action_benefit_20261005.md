# Exploratory actual-action benefit analysis, October 5, 2026

This analysis is specified after inspecting the completed fixed WaterDrop study. It is an exploratory postprocess, not an additional locked endpoint or independent confirmation. It uses only existing saved same-state records/arrays: faithful and corrected-NLL models at seeds 0, 1 and 2, exactly 100,000 updates, official test indices 3–29, and target frames 7, 106, 205, 304, 403, 502, 601, 700, 799, 898 and 1000. It loads no checkpoints, performs no inference/training, selects no new policy or checkpoint, and accesses no additional dataset records. The source and this protocol must be frozen before computing new outcomes.

## Questions and fixed actions

Does residual-risk ranking relate differently to the benefit of the actual selected graph than to the whole-dense intervention? Are helpful and harmful effects concentrated at high risk? How much hindsight headroom exists among the **already evaluated whole-frame actions**, and how much does allowing base/no expansion contribute? How concentrated are optional-degree increments?

The fixed actions are dense, random25, speed25 and previous-observed-base-risk25, with base as reference. Previous observed base risk is a teacher-forced score; it is not autonomous cached-own-graph risk. No selector search, risk permutation, additional random draw, or new graph inference belongs to this analysis.

## Per-particle and per-frame estimands

For saved target y and predictions p0 (base) and pa (action), compute each policy's vector squared error separately in position coordinates and in decoder-equivalent normalized coordinates, using the saved positive two-coordinate acceleration standard deviation. The latter divides each coordinate residual by its corresponding standard deviation before squaring; unequal scales can change benefit signs. Coordinate MSE is one-half of mean vector squared error in this 2D experiment.

For every action define signed benefit `b = ||y-p0||² - ||y-pa||²`. Positive is helpful, negative is harmful. With `r=y-p0` and `delta=pa-p0`, independently reconstruct `b = 2*r·delta - ||delta||²`; report mean alignment term and perturbation cost. This describes each complete graph action, not marginal edge utility, and shares the base residual algebraically. Correlation is descriptive and is not causal or evidence of general intervention value.

Retain per-particle errors, signed benefits, alignment and perturbation terms in derived NPZ files, with source-file hashes. Within each frame report equal-particle benefit, coordinate MSE, positive/negative/exact-zero fractions, and current-base/previous-observed-base risk versus benefit Spearman correlations using average ranks for ties. Two particles suffice; constant rank vectors or fewer than two particles give null with an explicit reason.

For each actual action and each coordinate system, retain the complete 3×3 cross-tabulation of dense-benefit sign versus actual-action-benefit sign (harmful, exact zero, helpful), its per-particle fractions, any-sign disagreement fraction, and strictly opposite nonzero-sign fraction. Dense versus itself is a zero-disagreement reference. Report the difference of each risk–actual-benefit correlation minus the corresponding risk–dense-benefit correlation within the identical frame. Also report current-risk minus previous-risk benefit correlations and their direct risk-rank Spearman agreement. Undefined constituent coefficients make the corresponding difference undefined.

Record whether each action's **whole-frame** mean benefit is positive, negative or exactly zero, then aggregate these indicators as frame frequencies. Separately take each trajectory's 11-frame mean benefit and count helpful/harmful/zero trajectories; retain undefined-trajectory counts and leave unconditional frequencies undefined when any required trajectory is undefined. These do not conflate a helpful average with every particle benefiting. Save all ten pairwise policy coordinate-MSE differences within identical frames in the fixed policy order (left minus right); aggregate the paired differences through the same trajectory/seed hierarchy. Also retain NLL-minus-faithful differences paired by the same training seed on every scalar metric. These are descriptive paired differences, not independent replicate significance tests.

For each risk vector, assign each particle's average rank r (one-based) to a fixed quartile using `(r-0.5)/N`: intervals `[0,.25)`, `[.25,.5)`, `[.5,.75)`, `[.75,1]`. All particles with an identical score stay together; there is no ID tie break. Groups may be unequal or empty. Save group count/fraction, mean signed benefit, and harmful fraction for each action and coordinate system. Empty groups have null means/fractions and remain represented. These are risk-stratified descriptive profiles, not a learned or deployed selector.

## Whole-frame hindsight portfolios and abstention

Compute the lowest **whole-frame coordinate MSE** among the fixed all-policy portfolio `{base,dense,random25,speed25,previous-observed-base-risk25}`. Separately use the budgeted portfolio `{base,random25,speed25,previous-observed-base-risk25}`. Base has zero optional edges; the other three budgeted choices retain the same fixed 25% pair count. The all-policy portfolio includes dense with greater graph cost and is not a matched-cost performance bound.

For each portfolio and coordinate system, report oracle coordinate MSE, base-minus-oracle benefit, previous-risk-minus-oracle headroom, best non-base coordinate MSE, and the improvement from including base (best-non-base error minus oracle error). Record whether base strictly beats every non-base choice, whether base is co-best, each selected choice, and number of tied best choices. Exact ties use the original policy ordering `base,dense,random25,speed25,previous-observed-base-risk25` restricted to that portfolio; all co-best information remains. These quantities use targets in hindsight and are **not deployable**, do not mix per-particle predictions, and are not the optimum over arbitrary edge subsets or future rollouts.

## Allocation structure

Verify saved base/annulus/selected pairs are unique simple unordered pairs in range, that every selected graph contains its mandatory base, and that selected optional pairs belong to the saved annulus. Dense must retain the entire annulus; the other three actions must retain exactly `floor(.25 * annulus_count)` pairs. Verify recorded pair counts, saved first-timed-call selected-pair hashes, and optional overlaps against the producer records.

From optional pairs only, count each particle's optional-degree increment. For each action report mean, maximum, second moment, nonzero coverage fraction, Gini coefficient over all particles, Herfindahl index of endpoint shares, and maximum endpoint share. Zero optional pairs give mean/maximum/second moment/Gini/coverage zero, but Herfindahl and maximum-share null because their denominator is zero. Report risk–optional-degree Spearman correlations and every pair of policies' optional-set Jaccard (both empty gives 1). These are descriptions of allocation structure, not a causal attribution of error.

## Aggregation, missingness and provenance

Average particles within frame, then exactly 11 frames within trajectory, then exactly 27 trajectories within seed. Report every trajectory and every seed. Across exactly three seeds report mean and sample SD (ddof=1), with the seed values retained. Do not pool particles, frames, objectives or timing calls into independent model replicates. No p-values, bootstrap intervals or selector-selection tests are part of this bounded analysis.

Keep all signed adverse outcomes. A failed/missing frame supplies null scientific metrics with its status/reason retained. A null required metric in a trajectory makes that trajectory's unconditional mean null; a null trajectory makes its seed mean null; a null seed makes its objective mean/SD null. Record defined counts and undefined reasons. Do not replace unconditional means with available-case means. Invalid hashes/schema/arithmetic stop the analysis and preserve its error status; this is an integrity failure, not an adverse scientific outcome to discard.

Use the existing strict six-model same-state loader to verify protocol/checkpoint/data/source identities, exact schedule, committed status/result/record/array hashes and cross-model input pairing. Independently check array shapes, finite values, saved history/target hashes, saved per-particle errors and dense benefits, and selected-pair semantics. Construct an input-file SHA256 inventory before analysis and verify every byte hash again afterward. Record checkpoint/data/source provenance and software versions in the new result. Never overwrite inputs or an existing analysis output directory. Preserve any partial output and error status. Derived results remain in a new output family and do not replace the locked study.
