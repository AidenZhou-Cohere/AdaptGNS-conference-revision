## Fixed observed states and policies

For every included trajectory use zero-based target frame indices **7, 106, 205, 304, 403, 502, 601, 700, 799, 898 and 1000**. There are 11 observed states per trajectory and 297 states per checkpoint. To predict target frame t, all policies receive the same six observed frames t−6 through t−1 and particle types. The previous-risk scoring pass receives the six observed frames t−7 through t−2 on its base graph. Thus target 7 uses current history 1–6 and previous history 0–5. Future target positions enter only residual diagnostics.

Compare base, dense, random25, speed25 and **previous-observed-base-risk25**. The last policy uses variance from the previous observed base-graph history. It is a teacher-forced lag diagnostic, distinct from the autonomous rollout controller that caches risk from its own evolving selected graph. Its previous mean prediction is discarded. No cached deployment cost is inferred or amortized away.

Use base radius 0.015, expanded radius 1.267 times base, uncapped symmetric undirected pairs, and no self loops. Retain exactly floor(0.25 times the available annulus pairs) for every budgeted policy. Speed is the norm of the last observed displacement. Scored pairs receive the maximum endpoint score; ties are resolved lexicographically by pair IDs. Random selection is reset to a fixed per-checkpoint-seed/source-index/target-frame stream for every repeat, so it uses the same subset across timing repetitions and across paired objectives for the same training seed. Selected pairs are canonically sorted before constructing directed message edges for all methods.

Radius classification in this companion diagnostic promotes the stored float32 coordinates to float64 for distance comparisons. Model history/features remain float32. This is not a claim of bit-identical graphs to the frozen autonomous evaluator, whose base/annulus classification computes squared distances in float32. Save actual pair identities and an untimed comparison against the frozen float32 candidate path, including any differing base or annulus pairs. Direct base-radius and expanded-then-filtered float64 base pairs must agree exactly.

## Residual and allocation diagnostics

Save per-particle squared position residuals and decoder-equivalent normalized acceleration residuals for each policy. If s is the saved acceleration standard-deviation vector, the latter residual is `(predicted_position − target_position) / s`; this equals the normalized acceleration residual up to float32 decoder rounding. Position MSE averages squared coordinate residuals. Scalar q is the model's converted per-coordinate normalized acceleration variance; vector squared residuals have predicted scale 2q in this 2D task.

Define signed dense-intervention benefit on the identical observed state as base vector squared residual minus dense vector squared residual, in both position and normalized units. Preserve negative values. This is a whole dense-graph intervention, not marginal edge utility or a causal guarantee for selected pairs. Report Spearman correlations of previous-observed-base q and current-base q with current base normalized vector error and signed dense benefit. Use average ranks for ties. Constant vectors and fewer than two particles produce undefined correlations; retain their counts and leave unconditional averages undefined when a required frame correlation is undefined.

Record mandatory/candidate/annulus/retained pair counts, exact optional budgets, saved selected pairs, pair overlaps and optional Jaccard similarity (both sets empty gives 1). Record cutoff scores, total pairs tied at the cutoff, admitted/rejected cutoff ties, and whether a tie straddles the selection boundary. Ties depend on particle IDs. Record benefit positive/negative/zero fractions without treating particles as independent training replicates.

Report equal-particle means within frames, then equal frames within trajectories, then equal trajectories. Also report pooled particle-weighted errors and benefits separately, since trajectory particle counts differ. An average of frame Spearman coefficients is distinct from a pooled particle Spearman coefficient; label both if supplied. No confidence interval or significance claim may treat individual particles or repeated runtime calls as independent trained-model replicates.

## Runtime measurement

Primary base timing builds only its natural radius-r graph; dense and budgeted methods search the expanded radius. The previous-risk method also builds and executes its previous observed base graph, with that score-generation cost included in end-to-end time and reported separately. Include feature construction, selection, canonical pair ordering, tensor transfers, model forward, decoding and synchronization. Residual/tie/overlap audits and artifact writing are measured separately from timed predictor calls.

Add one explicitly labeled computational reference, **base_shared_superset**, that runs the frozen `full_rollout.checked_candidates` expanded candidate path and retains only its base pairs, using this diagnostic's float64 classification. It must match the natural base pair set. It is not a sixth scientific allocation policy. Its imposed expanded-search overhead must not support a production speedup claim.

For each observed state perform one untimed warmup call for each of the six timing cases, then six timed rounds. Cyclically rotate all six cases so each case occupies every position exactly once. The starting rotation is fixed by source index and target-schedule index. Include the previous-risk score pass in every warmup and timed call. Save every measured call, warmup count/time, network-pass count, and per-case mean/median/sample SD across repetitions. Report repeated pair-set identities and maximum prediction differences; the first timed call supplies the declared residual/allocation diagnostics. Timing variation is descriptive, and no cached amortized deployment cost or general speedup follows from this reference implementation. Save device/software/thread/fallback settings; run on one device without concurrent experimental work when collecting publishable timings.

## Failures, provenance and restart

Check finite observed states, predictions and raw/converted risk; use the same computational limits of absolute predicted/state coordinates at most 10 and at most 100,000 candidate undirected pairs. The discarded previous scoring mean must be finite but is not an accepted state and is not subject to the absolute-coordinate cutoff. These are computational guards, not physical-validity tests.

A guard failure in any required warmup or timed call makes the frame diagnostic failed; preserve the failing case/repetition/phase and all completed call records. Full-sample aggregate errors and timings remain undefined if any required frame fails or is missing. Preserve undefined correlation counts; do not average only successful frames, surviving trajectories, or defined coefficients without explicitly qualifying the estimand. Validation overrides remain labeled validation, never locked test.

Use exclusive output ownership, source/data/checkpoint/protocol hashes, atomic per-frame array/JSON commits and a compact index. Resume only an identical protocol and verify every reused record and array checksum, including guard-failed records. An interrupted uncommitted frame may restart; a committed failed frame is not rerun to obtain a preferable result. Preserve partial and failed status.
